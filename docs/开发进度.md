# 定格 Stillframe 首版开发记录

日期：2026-11-09。工程根目录为 `/Users/liuwei/Documents/stillframe`。

## 结果

已完成可运行的本地 Web 应用，具备模板→导入→编辑→滤镜→下载的真实流程；不是将 SVG 原型包装成网页。代码、依赖、锁文件、构建产物、测试与启动脚本均在项目中。

采用 React 19、Vite 8、Less Modules、Base UI、Zustand／Immer、React-Konva、PixiJS、ExifReader、Dexie、Comlink、zip.js。TypeScript 实际锁定6.0稳定系列，以匹配当前 lint 工具的 peer 范围。UI 直接基于 Base UI 定制 Less 样式，没有加入额外 Tailwind 业务样式。

图像计算运行在 Worker；GPU 调色失败会采用相同公式的 CPU 降级。ZIP 首版是有预算的 Blob 分包，尚未接入直接落盘流。裁剪、多选组合、吸附、手写签名和跨设备同步属于后续阶段。

## 启动

双击工程根目录的 `启动定格.command`，使用Node24启动Vite并打开浏览器。

标准Node24环境中可运行 `pnpm dev`。完整命令和边界见README。

## 本地数据

照片原文件不上传、不覆盖。草稿仅保存编辑描述；刷新后重新导入相同照片，以SHA-256指纹恢复。预设及标识存于此浏览器IndexedDB，清理站点数据会清除它们。


## 后续调整：响应式、拍摄信息与主题

修复画廊模板与页面布局类名冲突，以及固定最小宽度造成的横向溢出；检查375、640、768、1024、1440px的模板库与工作台，body与document均无横向溢出。照片队列保留横向交互，但隐藏横向滚动条。

参数面板提供来源标记、手动填写、原始值恢复和显示字段选择；支持光圈、ISO感光度、焦距、快门、镜头和日期独立绑定。品牌库包括尼康、富士、佳能、徕卡、哈苏、索尼、松下、理光、宾得、OM/奥林巴斯、大疆、苹果，并支持自定义品牌。缺失EXIF不伪造值。

白色主题主色调整为#526DA6，选中背景#EEF2F8，画布控制手柄跟随主题；暗色保持浅香槟。新增参数／品牌／主题浏览器用例通过，单位用例共5项。

## 相机品牌 Logo

- 使用用户提供压缩包中的 9 个 PNG 标识，原文件映射见 public/brands/README.md。
- 导入时依据 EXIF Make 匹配品牌，兼容 NIKON CORPORATION、Leica Camera AG 等厂商别名。可在拍摄参数面板手动切换，恢复原始 EXIF 时重新匹配。
- 相机品牌绑定元素显示 Logo 与机型，保留拖动、缩放、旋转、显隐和历史记录；旧草稿及预设无需迁移。批量导出按每张照片的元数据匹配。
- 画布与导出使用同一布局函数与素材，导出 Worker 按需加载并缓存 Logo。所有品牌 Logo 保留原 PNG 透明背景，不添加底衬。未提供素材的品牌保留文字。
- 模板示例及参数面板也显示对应 Logo。原始照片不被修改。

## 边框分类筛选修复

原侧栏分类仅滚动定位卡片，且全部边框始终高亮，导致点击分类后仍显示全部模板。现已改为按分类筛选模板、同步选中高亮与标题数量，并使用 URL 查询参数保留分类，支持刷新及浏览器前进后退。已通过分类浏览器回归测试。

## 连续编辑工作台

- 两种起点：先选模板再导入，或先导入后在工作台切换模板。显式选择的模板优先于同一照片的历史草稿布局。
- 顶部导航简化为模板库、编辑工作台；工作台内设照片→模板→滤镜→导出步骤。左侧工具切换模板、滤镜、文字标识和图层，右侧属性随操作变化，点击画布元素可回到元素属性。
- EXIF 一直在导入时自动读取；此次增加常驻照片信息摘要与品牌 Logo，信息缺失时直接提示。编辑信息打开侧栏，不再要求从顶部独立入口进入参数页。
- 切换模板不弹确认，保留色彩、参数显示字段、签名及自定义文字/图片素材，并保留撤销；额外素材按画布边界重排。模板中的默认元素按新模板重新布局。
- 添加照片继承当前样式，单独读取原图 EXIF；批量应用样式不覆盖照片元数据。导出后留在工作台。
- 浏览器验证两种完整流程、EXIF 导入即展示、滤镜跨模板保留与撤销、正常导出；同时回归分类、标识、草稿和大图导出。375/768/1440px 无页面横向溢出，顶部与左右面板独立滚动。

## 操作栏调整

将工作台编号步骤条改为无顺序的编辑操作栏，去掉编号、连接箭头及步骤语义；照片、模板、滤镜、导出可随时点击，当前面板使用选中状态显示，并保留照片数量、模板与滤镜提示。

## 添加、替换与切换照片

- 顶部与队列的添加照片只增加队列项；工作台操作栏新增单张替换入口，文件选择器相互独立。底部缩略图标记为切换照片，当前项具有选中状态。
- 替换保留当前队列项 ID、模板、滤镜、参数显示选项及签名/个人图层；按新照片方向及宽高比重新适配，页脚元素随之移动并约束到画布内。
- 新照片重新校验文件、读取 EXIF 与品牌；不恢复新照片的旧草稿，也不沿用旧照片的 EXIF 或手动参数。缺失字段留空。无效文件或队列内重复照片被拒绝，当前照片保留。
- 历史从仅文档升级为完整照片快照，覆盖文件、URL、尺寸、元数据、原始 EXIF、指纹和场景。按照片保存历史，切换队列不会丢失撤销/重做；批量应用样式同样保留历史。对象 URL 仅在当前照片及所有历史均不再引用时释放。
- 验证：8 项单元测试通过；11 项浏览器测试通过。新增用例覆盖尼康→佳能替换、ISO 手动值清除、无 EXIF 替换、无效文件、添加与切换、跨切换撤销重做、签名/滤镜保留、竖图布局与导出 EXIF 确认。撤销记录属于当前会话，草稿保存当前状态。

## 画布文字边框与对齐

画布文字改用字体实际可见范围计算选中边框，去除固定文本区域产生的空白选区；文字在布局区域内垂直居中，保留左/中/右水平对齐。预览与导出共享排版与字体度量逻辑，支持中文、英文下伸字符和多行文本。文字拖动缩放使用贴合文字的选区，缩放保持字形比例；空文字仍保留可点击的编辑区域。
