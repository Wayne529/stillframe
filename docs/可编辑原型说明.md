# 定格 · Stillframe｜可编辑模板原型 v0.4

日期：2026-11-09。沿用已认可的画廊质感风格，新增可编辑模板的界面和操作演示。品牌名称本轮按「定格 / Stillframe」展示，尚未做名称可用性核验。

## 现在包含什么

新增「自由编辑」工作台：

- 照片、相机品牌、拍摄参数、手写签名、相纸背景共五个元素。
- 左侧图层列表，可选中、显示／隐藏、锁定／解锁。
- 画布元素选框及八方向缩放手柄。
- 右侧 X/Y、宽高、不透明度数值输入，保持比例开关。
- 左／中／右、上／中／下对齐到画布。
- 拖动、缩放、数值编辑、显隐、锁定和对齐均可撤销／重做。
- 一次拖动或缩放作为一条历史记录。
- 另存个人预设弹窗、命名、保存及恢复。浏览器允许时写入本地存储；不允许时清楚提示仅本次会话保存。
- 切换主题保留当前布局。

照片、Logo／签名默认保持比例；拍摄参数的文字框调整宽度时进行换行，不直接把文字横向拉变形。参数绑定规则随个人预设保存，而非把样片参数固定为其他照片的值。

## SVG 与 HTML 的区别

**SVG 为静态设计状态稿。** 展示元素、控制手柄、属性面板和保存弹窗，内部导航链接可跳页；单独打开 SVG 不运行拖动与存储逻辑。

**《可编辑模板原型.html》为可操作演示。** 可离线打开，默认进入自由编辑页。拖动、缩放、键盘方向键、位置尺寸、比例开关、透明度、显隐／锁定、对齐、撤销／重做、保存／恢复预设可操作。

此 HTML 用原生 SVG 事件验证产品交互，不代表已创建 React／Konva 生产工程。其他页面继续作为流程示意；上传、真实滤镜、照片裁剪、高清图片编码、批量应用和 ZIP 下载尚未实现。演示仅编辑当前样片，不宣称完成多照片图像处理。

4. 02-滤镜调色.svg：滤镜示意，加入自由编辑入口。

使用 SVG 文件链接时请保留目录结构。SVG 内嵌摄影图片，可离线查看；文字、选框、布局和签名仍为矢量。部分数值框使用 foreignObject，浏览器可显示；某些设计软件导入时可能忽略此类输入框，评审以浏览器渲染为准。

## 操作方式

- 从画布或左侧图层选中元素，拖动移动。
- 拉动选框边角缩放；右侧可切换比例约束。
- 方向键移动 1 个画布单位，Shift＋方向键移动 10 个单位。
- Ctrl／⌘ Z 撤销，Ctrl／⌘ Shift Z 重做；Escape 取消当前拖动。
- 默认锁定相纸背景，避免误操作。
- 点击「另存个人预设」，命名后保存；「我的个人预设」可恢复布局。
- 此版本提供经典参数模板的交互演示，其余模板卡片用于样式参考，点击时会说明进入经典演示。

## 检查结果与边界

已通过 Chrome 实际指针事件验证拖动和缩放，检查比例约束、位置输入、锁定阻止拖动、显隐、撤销／重做、保存与恢复，以及主题切换保留布局。已完成暗亮主题和保存弹窗的渲染查看，并检查 SVG XML 与导航目标。

未把这些验证扩展成生产兼容性承诺：Safari、移动端触控、旋转、多选组合、吸附、跨照片批量、用户文件上传及真实导出仍需在业务工程中实现或测试。
